Hide or restore the apps ZimaOS ships built in, and see every installed module.

Hide takes an app off the dashboard and stops its services. Nothing is deleted: Restore brings it back exactly as ZimaOS shipped it. ZimaOS keeps the apps in its read-only system image, so they can be hidden but not removed. Data stays until you choose Delete data for a hidden app.

Install modules from GitHub releases. A module runs as root on this host. A GitHub image is installed only when its release ships a sha256 checksum and the download matches it — that proves the file arrived intact, not that its author can be trusted: the checksum comes from the same release. Modules keep their data in /DATA/AppData when removed.

The latest release must contain a sysext image (name-amd64.raw or name.raw) and its checksum.
Add only repositories whose author you trust. An installed module runs as root and can read and change everything on this ZimaOS host; the checksum does not check that.
